# マイクロマウス ターンシミュレーター

最短走行のターン(大回り90/180、斜め入り45/135、斜め出45/135、V90)を、
**少ない実走行で調整する**ためのシミュレーター。クラシック(区画180mm)とハーフ(区画90mm)の両方で使える。

調整の手順は pidream「ターン調整のルーティン」(マイクロマウス Advent Calendar 2024 1日目、
https://www.pidream.net/2024/12/241201.html )に沿っていて、画面の左に手順が並んでいる。

## 使い方

**https://tokoro0917.github.io/Turn-Sim_KOGUMA/** を開く(GitHub Pages)。
clone して `index.html` をブラウザで開いてもよい(インストール不要、オフラインで動く)。

1. 上の切り替えで **クラシック / ハーフ** を選ぶ(設定はサイズごとに別々に保存される)
2. 左の手順を上から順に進める。各手順に「シミュレーター」か「実機」の印が付いている
3. 終わったら「Cの表をコピー」で機体のソースに貼る。「保存 (JSON)」で設定をファイルに残せる

入力した値はブラウザ(localStorage)に保存される。別のブラウザやPCに移すときは JSON で保存・読み込みする。

## モード

画面右上で切り替える。

- **調整の手順**: 下の9つの手順に沿ってターンを合わせる
- **自由設定**: ターンの重心速度・角速度・角加速度・前後の距離を自由に入れて、軌跡と、ターン中の速度・加速度(横・前後・合成)のグラフを見る。ターン中に減速する「最低速度」も設定できる(下のモデルを参照)。グリップの使用率は、手順で合わせた斜め入り45のピーク合成加速度を基準(100%)にして表示する
- **最適化**: 斜め入り45のピーク合成加速度を基準にして、それを超えない範囲で各ターンの一番速い速度(速度一定)を探し、そのときの角速度・角加速度・前後の距離を出す。基準は手入力もできる

最適化の基準にする斜め入り45は、手順7(ばらつきの確認)まで済ませて、実機で安定して曲がれることを確かめたものを使う。
ターン中に減速する場合も試したが、入口=出口の速度のまま減速すると前後の加速度がグリップの余裕を食うので、このモデルでは最高速度は上がらなかった。そのため最適化では使っていない。

## 手順

| # | 場所 | 内容 |
|---|---|---|
| 1 | 準備 | 目標速度、角加速度の上限、各ターンの「曲がり始めの下限」(壁切れを検出する位置)を入れる |
| 2 | シミュレーター | 一番曲がりにくい斜め入り45を作る(曲がりにくさ: V90 ≧ 斜め入り45 ≫ 斜め入り135 ≫ その他) |
| 3 | 実機 | 停止位置テスト: 加速の直線 → 斜め入り45 → 斜め直線(**壁制御は切る**)で停止。理想の停止位置からのずれを測る |
| 4 | シミュレーター | 測った横ずれに合うスリップ係数 k を求める |
| 5 | シミュレーター | その k で斜め入り45を作り直す。作れなければ「出せる一番速い速度」を探せる |
| 6 | 実機 | もう一度走らせ、残ったずれを前後の距離で消す(前後・横の両方を2つの距離で直す) |
| 7 | 実機 | 走行ログで角速度・角加速度の追従と制御量の張り付きを確認し、何度か走らせてばらつきを見る(既定 ±3mm) |
| 8 | シミュレーター | 同じ k で残りのターンを作る(速度はターンごとに変えてよい) |
| 9 | 実機 | V90 が3つ続く迷路で確認(天井カメラで軌道を撮ると早い) |

## モデル

- 重心速度は入口・出口が v で、ターン中は角速度に連動して変えられる: v(t) = v − (v − v最低)·ω(t)/ω最大(角速度が最大のときに最低速度。最低速度 = v なら速度一定)。加速度は横 v·ω と前後 dv/dt を合成した値(摩擦円)で見る。角速度は cos 型の加速 → 等角速度 → cos 型の減速(角度が足りなければ三角形になり、ピーク角速度は自動で下がる)
- 機体の向きはジャイロ制御で角速度の目標どおりに回る(角度の誤差は出ない)
- タイヤの横滑り: 進む向きが機体の向きから旋回の外側へスリップ角 β だけずれる

  β[deg] = k × 横加速度[m/s²]、横加速度 = v·ω

  記事の「スリップ角は遠心力 m·v·ω に比例する」というモデル。記事では速度一定として β ∝ ω だが、ターンごとに速度を変えても同じ k が使えるよう v·ω で持つ。タイヤが滑り始める領域(グリップの限界付近)では比例関係が崩れるので、そこではシミュレーターは合わなくなる(手順7のばらつきで見分ける)
- 前・後の距離は「理想のターン開始点から曲がり始めるまで」「曲がり終わってから理想の終了点まで」の距離。壁切れを検出してから曲がる機体では、壁切れの位置より手前では曲がり始められないので、手順1の「曲がり始めの下限」にその位置を入れる
- 理想の開始・終了点は迷路の幾何で決まる: 大回り・斜め入りは区画中心から、斜め出・V90 は斜めの壁の中点から。ハーフはクラシックをちょうど半分にした幾何
- 計算は左ターンだけ。右ターンは鏡像

「作る」ボタンは、角加速度が上限以下・前が曲がり始めの下限以上・後が下限以上という条件で、**ピーク横加速度が一番小さくなる**角速度・角加速度と前後の距離を探す。

## 初期値について

- 曲がり始めの下限の初期値は、KOGUMA.MkIIl(クラシック)の調整済みパラメータから逆算した目安(ハーフはその半分)。自分の機体の壁切れ位置に置き換えること
- 角加速度の上限の初期値(クラシック 130000、ハーフ 250000 deg/s²)は仮の値。モーターが出せる値を入れる
- 速度の初期値はクラシック 2000、ハーフ 1300 mm/s(記事の目安: ハーフ・吸引ありで 1.3〜1.4 m/s)
